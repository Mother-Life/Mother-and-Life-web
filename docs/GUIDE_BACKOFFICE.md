# Guide back-office Mother & Life

## Connexion

1. Aller sur `motherandlife.org/admin`
2. Se connecter avec l'email fourni par l'administrateur
3. Mot de passe fort obligatoire (verrouillage après 5 échecs)

## Rôles

| Rôle | Peut faire |
|------|-----------|
| Admin | Tout, y compris gérer les comptes |
| Éditeur | Créer, modifier et **publier** tout contenu |
| Rédacteur | Créer des brouillons — **ne peut pas publier** |
| Finance | Gérer dons, rapports, chiffres clés |
| Lecteur | Consultation seule |

## Publier un article

1. **Actualités** ? **Créer**
2. Remplir titre, chapo (max 200 car.), catégorie, couverture
3. Composer le contenu avec les blocs
4. Rédacteur : cliquer **Soumettre pour relecture**
5. Éditeur : cliquer **Publier**

## Ajouter une photo

1. **Médiathèque** ? **Créer**
2. Remplir obligatoirement :
   - **Alt** (description pour l'accessibilité)
   - **Type** (activité, portrait, événement…)
   - **Date de prise**
   - **Consentement** (écrit obligatoire pour portraits/activités)
   - **Contient mineur** (si oui ? consentement écrit obligatoire)
3. Nommer le fichier selon la convention : `AAAA-MM_type_pilier_antenne_sujet_NNN.jpg`

## Confirmer un don

1. **Dons** ? filtrer par statut « Déclaré »
2. Vérifier le montant sur Mobile Money / relevé bancaire
3. Passer le statut en **Confirmé**
4. Générer le reçu si demandé

## Chiffres clés

Modifier uniquement via **Chiffres clés** (global). Toujours indiquer la source et la date de mise à jour.

## Ne jamais faire

- Publier une photo sans consentement écrit
- Uploader le PV de l'AG (contient des numéros CNI)
- Modifier les chiffres sans source vérifiable
